# ARD specification files (test fixtures)

`ard-entry.schema.json` and `ard.context.jsonld` are unmodified copies of the official Agentic Resource Discovery
specification files, used only by `tests/validate-ard-manifest.py`. They are not deployed.

- Source: https://github.com/ards-project/ard-spec, `spec/schemas/`, commit `f073b1e` (2026-10-25), spec version v0.91
- License: Apache License 2.0 (https://github.com/ards-project/ard-spec/blob/main/LICENSE)

When the spec is revised, replace both files from the new commit, update this note and rerun the ARD tests.
